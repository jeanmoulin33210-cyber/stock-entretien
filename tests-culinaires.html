🔐 Sécurité administrateur

    
🛡️
Protection non activéeActivez un PIN avant de distribuer les liens testeurs.

    

      

      

    

    
Deux protections sont utilisées : un jeton administrateur aléatoire distingue le lien administrateur des liens testeurs, et le PIN verrouille l’interface administrateur. Seule l’empreinte de ces secrets est synchronisée dans le jury.

    
Cette protection sécurise l’accès dans l’application. Pour une sécurité serveur complète des données Supabase, une authentification Supabase avec des règles RLS dédiées resterait une évolution supplémentaire.
